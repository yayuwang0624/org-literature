#+TITLE: org-literature

A paper library for Emacs, built on [[https://github.com/emacs-citar/citar][citar]], [[https://github.com/org-noter/org-noter][org-noter]] and [[https://github.com/vedang/pdf-tools][pdf-tools]].

All papers live in one folder. One BibTeX file holds every entry, PDFs are
named after their citation key, and each paper has one org note.

#+begin_example
literature/
├── refs.bib        one entry per paper, tags in the keywords field
├── pdf/<key>.pdf   the papers
└── note/<key>.org  one note per paper
#+end_example

* What is in this repository

| File                    | What it does                                                       |
|-------------------------+--------------------------------------------------------------------|
| =org-literature.el=     | add papers, add PDFs, edit tags, suggest citation keys, find notes |
| =org-pdftools.el=       | the =pdf:= org link type, pointing into a page or an annotation    |
| =org-noter-pdftools.el= | precise org-noter notes tied to PDF annotations                    |

Install and load only =org-literature=. It loads the other two files itself.
=org-pdftools.el= and =org-noter-pdftools.el= come from
[[https://github.com/fuxialexander/org-pdftools][fuxialexander/org-pdftools]], with a few fixes. Their history is kept in
this repository.

* Install

Requirements are Emacs 29.1 or newer, citar, org-noter and pdf-tools.

Clone the repository and load it from its folder.

#+begin_src emacs-lisp
(use-package org-literature
  :load-path "~/Project/org-literature/"
  :after citar
  :demand t
  :config
  (org-literature-mode))
#+end_src

Or let Emacs fetch it.

#+begin_src emacs-lisp
(use-package org-literature
  :vc (:url "https://github.com/yayuwang0624/org-literature" :branch "master")
  :after citar
  :demand t
  :config
  (org-literature-mode))
#+end_src

* Setup

Set the library folder before the package loads. The other three paths
follow it unless you set them too.

#+begin_src emacs-lisp
(setq org-literature-directory "~/org/literature/")

(use-package citar
  :custom
  (citar-bibliography (list org-literature-bibliography))
  (citar-library-paths (list org-literature-pdf-directory))
  (citar-notes-paths (list org-literature-notes-directory))
  (citar-note-format-function #'org-literature-format-note))

(use-package org-noter
  :custom
  (org-noter-notes-search-path (list org-literature-notes-directory))
  (org-noter-find-additional-notes-functions '(org-literature-note-for-document)))
#+end_src

Loading =org-literature= also loads =org-pdftools= and =org-noter-pdftools=,
so they need no =use-package= of their own.

| Variable                         | Default                          |
|----------------------------------+----------------------------------|
| =org-literature-directory=       | =literature/= in =org-directory= |
| =org-literature-bibliography=    | =refs.bib= in that folder        |
| =org-literature-pdf-directory=   | =pdf/= in that folder            |
| =org-literature-notes-directory= | =note/= in that folder           |

* Commands

The package binds no keys. Bind the commands you use.

| Command                       | What it does                                                    |
|-------------------------------+-----------------------------------------------------------------|
| =org-literature-add-paper=    | add a paper from BibTeX, a DOI, an arXiv ID or link, or a title |
| =org-literature-attach-pdf=   | save a PDF for a paper, from a file, a link, or its DOI         |
| =org-literature-open-entry=   | jump to a paper's BibTeX entry                                  |
| =org-literature-edit-tags=    | edit the tags of one paper                                      |
| =org-literature-rename-tag=   | rename a tag in every paper, or remove it with an empty name    |
| =org-literature-search-notes= | search the text of all notes with =consult-ripgrep=             |
| =org-literature-search-pdfs=  | search the text of all PDFs with ripgrep-all                    |

In a paper's note or PDF, the commands that take a paper use that paper.
Elsewhere they ask you to pick one.

** Adding a paper

=org-literature-add-paper= reads the region, or offers the clipboard when it
holds BibTeX, a DOI or an arXiv link. Otherwise it asks for input.

| Input               | Source                                                       |
|---------------------+--------------------------------------------------------------|
| BibTeX              | used as it is, after cleanup                                 |
| a DOI or DOI link   | Crossref                                                     |
| an arXiv ID or link | arXiv                                                        |
| a title             | Crossref, then Semantic Scholar, showing close title matches |

Then it suggests a key, asks for tags, and offers to download the PDF. A
download is kept only when the file is a real PDF. The cleanup drops foreign
=keywords=, =abstract= and =month= fields, keeps one link in =url=, and
stops when the title is already in the library.

Suggested keys are the first author, the year, and the system name before a
colon, for example =yarom2016cachebleed=. Titles without a system name give
the first two real title words, for example =brumley2003remotetiming=.

** org-literature-mode

The mode does three things.
- It registers the =pdf:= link type in org.
- It makes a click on a PDF annotation jump to its org-noter note.
- It adds an /Add PDF/ choice to =citar-open= for any paper without a PDF.
  Picking it runs =org-literature-attach-pdf=.

* PDF links and precise notes

These come from org-pdftools.

A =pdf:= link points to a page, or to an annotation on a page.

#+begin_example
[[pdf:~/file.pdf::3][Link to page 3]]
[[pdf:~/file.pdf::5++0.00;;annot-5-0][file.pdf: Page 5; Quoting: some text]]
#+end_example

In a pdf-tools buffer, =org-store-link= stores the current page. With text
selected, it also marks up the text and stores the annotation ID.

With org-noter, =org-noter-pdftools-insert-precise-note-underline= and its
siblings for highlight, squiggly and strikeout insert a note tied to one
annotation. =org-noter-pdftools-jump-to-note= jumps from an annotation to its
note. =org-literature-mode= runs it when you click an annotation.

=org-noter-pdftools-embed-org-note-to-pdf= copies a note into its PDF
annotation, and =org-noter-pdftools-embed-all-org-note-to-pdf= copies all of
them.

* Development

#+begin_src sh
make test      # ERT tests, each on a temporary library
make compile   # byte-compile, warnings are errors
make clean
#+end_src

The Makefile loads packages from =~/.emacs.d/elpa=. Set =ELPA= to use
another folder.
